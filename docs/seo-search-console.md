# Search Console launch checklist

1. Verify `https://barootcnc.com` ownership in Google Search Console.
2. Submit `https://barootcnc.com/sitemap.xml`.
3. Confirm `robots.txt` allows indexing and points to the sitemap.
4. Inspect `/`, `/learn`, `/learn/what-does-cnc-stand-for`, `/learn/what-is-cnc-machining`, `/learn/cnc-solutions`.
5. Confirm `title`, `description`, canonical URL and schema render (view source).
6. Use URL Inspection > Request indexing for priority pages.
7. Watch Coverage and Core Web Vitals after 7-14 days.
8. Check that `/learn` pages are indexed, not soft 404.
